Documentación de la API

1. Geocodificación

Permite buscar una ciudad y obtener sus coordenadas.

Elemento Descripción
Endpoint geocoding-api.open-meteo.com/v1/search
name Nombre de la ciudad.
count Cantidad de resultados solicitados.
language Idioma de los resultados.
format Formato de respuesta JSON.
latitude / longitude Coordenadas de la ciudad.

2. Pronóstico del clima

Permite consultar las condiciones meteorológicas actuales.

Elemento Descripción
Endpoint api.open-meteo.com/v1/forecast
latitude Latitud de la ciudad.
longitude Longitud de la ciudad.
current Solicita los datos actuales.
temperature_2m Temperatura en grados Celsius.
relative_humidity_2m Humedad relativa.
wind_speed_10m Velocidad del viento.
